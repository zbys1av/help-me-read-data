# Gyro RTP Analyzer

Окреме Chrome Manifest V3 розширення. Не змінює Work Mega Tool або код Gyro. Без бібліотек, збірки, API-ключів, серверів чи збереження статистики. Дані живуть у пам’яті бічної панелі. Розширення не читає cookies, паролі або токени й не виконує мережевих запитів. Пагінація використовує звичайні кнопки вже авторизованої сторінки.

## Встановлення

1. Завантажте папку `gyro-rtp-analyzer` на свій комп’ютер.
2. Відкрийте `chrome://extensions`, увімкніть **Developer mode**.
3. Оберіть **Load unpacked** → папку `gyro-rtp-analyzer` (всередині має бути `manifest.json`).
4. У Chrome 114+ відкрийте Gyro, авторизуйтеся звичайним способом і виберіть гравця, період та таблицю Games.
5. Натисніть іконку розширення → **Scan Data**. Оберіть вкладку гри; наведіть на точку графіка або використайте Tab. Пошук фільтрує назви і провайдерів.

## Межі перевіреної роботи

Алгоритм RTP перевірено автоматичними тестами. Живу авторизовану сторінку Gyro та завантаження розширення у Chrome в цьому середовищі не перевірено. Скріншот не розкриває DOM. Це встановлювана реалізація з діагностичним DOM-зчитувачем, але не підтверджена інтеграція з усіма варіантами таблиці Gyro.

Зчитувач шукає semantic `table`, `role=grid` або `role=table` та колонки за текстом заголовків: `Date`, `Game provider`, `Game name`, `Bets (count)`, `Bets (sum)`, `Wins (sum)`; резервна дата — `Date From`. Формати дат: DD/MM/YYYY, DD.MM.YYYY або YYYY-MM-DD. Порожня дата успадковується від попереднього рядка. RTP сайту не використовується: суми виграшів діляться на суми ставок. Валюта не конвертується; скануйте лише одну валюту одночасно.

## Адаптація фактичної таблиці

Відкрийте **Діагностика та адаптація DOM**. За потреби введіть CSS-селектори таблиці, поля User ID, поля періоду й кнопки наступної сторінки, перевірені в DevTools. Селектори не задані наперед, бо структура сайту невідома. User ID також визначається за зв’язаним label `User ID` або параметрами URL `userId` / `user_id`. Період без селектора лишається невідомим; діапазон прочитаних дат показано окремо.

Кнопка пагінації має ставати disabled / aria-disabled=true або зникати на останній сторінці. Сканування читає поточну та наступні сторінки: **перед скануванням перейдіть на першу сторінку таблиці**. Повтор сторінки й таймаут зупиняють обхід. Максимум 200 сторінок. Повернення на першу сторінку автоматично не виконується. Жодні невідомі кнопки не натискаються.

Віртуалізовані, canvas-таблиці, iframe, shadow DOM, складні багаторядкові заголовки та rowspan потребують адаптера у `scanner.js`. Поточний зчитувач не прокручує невідомий контейнер і **завжди позначає результат як непідтверджений щодо повноти**. При об’єднаних клітинках рядки пропускаються з попередженням. Скорочені назви з багатокрапкою без повного `title` пропускаються, щоб не змішати різні ігри.

Однакові записи без стабільного ID неможливо безпечно відрізнити від двох реальних однакових записів. Вони сумуються з попередженням; повторний Scan Data повністю замінює результат. Для точної дедуплікації джерела потрібен реальний ідентифікатор рядка в адаптері. Зміни DOM, фільтрів, навігація або перемикання вкладки скидають результат; повторіть сканування. Фонові зміни сторінки теж можуть вимагати повторного сканування.

Для завершення інтеграції потрібен знеособлений DOM-фрагмент із заголовками, рядками, полями User ID / періоду та елементами пагінації або віртуалізації. Не надавайте cookies, токени чи особисті дані. До перевірки адаптера результат не слід вважати статистикою всього періоду.

## Перевірки

З кореня репозиторію: `node tests/core.test.mjs` (7 тестів). Перевірено локалізовані числа, дати, зважений RTP, значення понад 100%, розділення провайдерів, нульові ставки, неповні рядки та заміну результатів сканування. Синтаксис: `node --check gyro-rtp-analyzer/scanner.js` і `node --check gyro-rtp-analyzer/panel.mjs`.

Ручна перевірка у Chrome: звірте суми однієї гри з Gyro; перевірте двох провайдерів з однаковою назвою, повторне сканування, зміну User ID / періоду, нульові ставки та таблицю з кількома сторінками. Ці браузерні перевірки ще не виконано.
